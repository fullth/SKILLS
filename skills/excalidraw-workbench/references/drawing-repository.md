# 도면 저장소 연결

- 저장소: https://github.com/fullth/excalidraw-work
- 용도: 편집 가능한 `.excalidraw` 원본과 PNG 등 도면 이미지 보관
- 공개 설정: 비공개 저장소다. 원본과 이미지 모두 저장소의 접근 권한을 따른다. 동기화 전에 현재 공개 상태를 다시 확인한다.

사용자가 GitHub 저장 또는 동기화를 요청한 경우에만 반영한다. 다른 저장소나 브랜치를 지정하면 사용자의 지정을 우선한다. 기본 저장소의 존재와 접근 권한은 GitHub 인증 계정과 저장소 조회로 확인하고, 토큰이나 자격 증명을 출력하거나 파일에 기록하지 않는다.

원격의 최신 대상 브랜치와 기존 파일을 확인하고, 요청한 도면의 원본과 이미지만 선별해 갱신한다. 공유 캔버스에서 내보낼 때는 다른 도면과 연결 관계를 함께 확인한다. 저장소의 기존 작업을 보존하고 사용자의 Git 및 push 전 검토 규칙을 따른다. 반영 후 원격 커밋과 파일을 확인해 링크를 제공한다. 캔버스와 GitHub 사이에 자동 동기화가 있다고 가정하지 않는다.

저장소 접근이 거부되거나 대상을 확인할 수 없으면 다른 계정이나 공개 저장소로 대체하지 말고 확인된 상태를 보고한다.
